# 搜图神器

鸿蒙网页封装（参考 TapTapWeb 工程），把搜图神器网页端当独立应用使用。

- 主页地址：https://soutushenqi.com/image/feature（可在应用内下拉设置中修改为任意网址）
- 包名：com.hmos.soutu
- 应用名：搜图神器
- 图标：取自官网网页图标（favicon）

## 功能

1. 下拉点设置按钮，填写主页地址，点保存即可。
2. 下拉默认为刷新及功能按钮（3秒缩回）。
3. 侧滑返回上一页。
4. 网页深浅色模式自动适配系统；设置中可打开"强制深色模式"。
5. 沉浸式系统栏：状态栏/小白条全透明，自动按页面背景取色调整图标深浅（参考 aira-browser 方案）。
6. 长按网页图片/视频弹出菜单：图片可保存至图库/复制链接，视频可复制链接/用其他应用打开（移植自 aira-browser）。
7. 网页内跳转第三方应用链接（应用深链 scheme）时自动拉起对应外部应用；未安装时提示。
8. **UA 伪装安卓客户端**：默认以 Android Chrome 手机 UA 访问，网页按安卓手机环境渲染；设置中可切换 电脑 / 自定义 UA。
9. **缓存优化**：WebView 缓存与 localStorage 持久保留，尽量少重复加载；启动时对主页预连接（prepareForPageLoad）加速首屏。缓存保留超过 **7 天**自动清除（每次启动刷新计时）。
10. 可以最多开启5个分身。
11. 其它的自行摸索。

## 构建

本地 AppScope/app.json5 已声明 bundleName `com.hmos.soutu`；若使用自有工程外壳，请把 bundleName 同步改为 `com.hmos.soutu`。

安装：用小白安装。
