# 搜图神器

鸿蒙网页封装（参考 TapTapWeb 工程移植），把搜图神器网页端当独立应用使用。

- 主页地址：https://soutushenqi.com/image/feature（应用内下拉设置中可改为任意网址）
- 包名：com.hmos.soutu
- 应用名：搜图神器
- 图标：取自官网网页图标（favicon）

## 功能

1. 下拉点设置按钮，填写主页地址，点保存即可（设置面板常显首页地址行）。
2. **UA 伪装安卓客户端**：默认 Android Chrome 手机 UA，网页按安卓手机环境渲染；设置面板常显 UA 行，可切 电脑 / 自定义。
3. **以图搜图上传适配**：网页图片上传控件自动拉起系统图库选图（onShowFileSelector）。
4. **详情浮层**：首页/搜索页点击图片进详情时，详情在独立 Web 浮层中打开；侧滑返回关闭浮层，底层页面保持挂载原状——不重载、不丢滚动位置。详情页内点击站点返回键回首页同样直接关闭浮层。
5. 长按网页图片/视频弹出菜单：图片可保存至图库/复制链接，视频可复制链接/用其他应用打开。
6. 网页深浅色模式自动适配系统；设置中可打开"强制深色模式"。
7. 沉浸式系统栏：状态栏/小白条全透明，自动按页面背景取色调整图标深浅；二三级页面自动避让状态栏。
8. 网页内跳转第三方应用链接（应用深链 scheme）时自动拉起对应外部应用；未安装时提示。
9. **缓存优化**：WebView 缓存与 localStorage 持久保留，尽量少重复加载；启动预热内核+主页预连接；缓存保留超过 **7 天**自动清除（每次启动刷新计时）。
10. Cookie 登录能力保留（已保存 Cookie 启动时自动写入），设置面板入口按需求隐藏。
11. 下拉默认为刷新及功能按钮（3秒缩回）；侧滑返回上一页；可以最多开启5个分身。
12. 其它的自行摸索。

## 与 TapTapWeb 壳的差异

- 移除全部 TapTap 网页适配：伪装 TapTap 客户端 UA、发布器/纯 Web 页 UA 自动切换、taptap:// 深链回退映射、底部"打开App"条点击屏蔽与底栏抬高、首页信息流快照缓存、TapTapAPI 注入脚本。
- 设置面板：显示首页地址与 UA 行（原壳 1.7.9 默认隐藏）、隐藏 Cookie 按钮。

## 构建

本地 AppScope/app.json5 已声明 bundleName `com.hmos.soutu`；若使用自有工程外壳，请把 bundleName 同步改为 `com.hmos.soutu`。

安装：用小白安装。
